- B2: zero-crossing convention. The framework does not specify which sample marks a zero crossing of Fx. A first version used the sample nearest zero; per-trial EQ then differed from the pre-event verification by up to 1.6 points (calibration medians unchanged). Adopted the convention under which all expected values were verified: the first sample after the sign change (zero counts as positive). Result: per-trial EQ (window 1, window 2, linear-detrend option) identical to the verification to 1e-14 over all 1,930 trials.
